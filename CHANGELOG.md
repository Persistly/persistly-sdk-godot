# Changelog

## 0.9.0

- Release candidate for the first public Godot SDK repository.
- Keeps the runtime API focused on create, load, sync, local cache, typed sync status, and structured runtime errors.
- Documents `saveId` persistence and integer save `version` semantics through the pinned contract bundle.

## 0.1.0

- Initial Godot SDK candidate for Persistly create, load, sync, local cache, typed sync status, and structured runtime errors.
- Includes Last Beacon playable sample for engine validation.
- Pins `persistly-contract-v0.1.0` for OpenAPI, examples, and runtime payload limits.
